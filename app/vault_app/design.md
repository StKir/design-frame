# Vault — база знаний с ИИ

Мобильное приложение для сбора и поиска знаний. Пользователь добавляет фото, документы и текст — нативный OCR распознаёт содержимое, данные индексируются в RAG-контейнер, ИИ отвечает по базе.

## Экраны

1. **Мои контейнеры** — список карточек, кнопка «Создать контейнер»
2. **Контейнер · Данные** — Google Drive-флоу: поиск, сортировка, список файлов, FAB загрузки
3. **Контейнер · ИИ Чат** — диалог с цитированием источников
4. **Контейнер · Настройки** — модель, системный промпт, параметры RAG

Таб-бар: Данные · ИИ Чат · Настройки

## Дизайн

- Минималистичный, строгий, много воздуха
- Акцент: `#2B2B2B` + `#2374EE`
- Фон: `#F6F6F8`
- Данные: компактный header, search bar, file rows как в Google Drive
