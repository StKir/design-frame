# Coach — курсы каллиграфии

Светлый минималистичный дизайн для курса каллиграфии. Визуальная доминанта — мягкий бумажный фон, тёплый radial glow, белые карточки и контрастные тёмные CTA.

## Экраны

1. **Главная** — приветствие, продолжение урока, путь курса, задание дня, галерея работ
2. **Курс** — roadmap курса «Основы каллиграфии»
3. **Урок · Теория** — обложка урока, основные тезисы, теория, термины, ошибки
4. **Упражнение** — пошаговый гайд, задание, загрузка фото на проверку
5. **Типы упражнений** — обводка, таймер, повторы, слово, мини-квиз, разминка
6. **AI Чат** — чат с коучем по уроку
7. **Профиль** — статистика, работы, настройки

## Дизайн

- Фон: `#F7F6F4` + мягкий тёплый radial glow
- Карточки: белые с лёгкой тенью
- Типографика: system sans, без serif
- CTA: тёмная кнопка на светлом фоне
- Изображения: тематические фото каллиграфии, бумаги, пера и рукописных работ
