Раздел 1 — Простые формы и архитектурные рисунки

1. Архитектурные линии

Самое простое упражнение.

Рисунок: небольшая композиция из архитектурных линий:

горизонтальные линии;
вертикальные линии;
параллельные линии;
короткие линии;
простые углы;
простые пересечения.

Например, пользователь постепенно собирает условный фрагмент стены с несколькими горизонтальными членениями.

Навык: аккуратно проводить прямые архитектурные линии.

2. Простейшие архитектурные элементы

Рисунок: композиция из базовых элементов фасада.

Постепенно появляются:

прямоугольное окно;
дверь;
подоконник;
простая линия карниза;
простая цокольная линия;
несколько горизонтальных членений фасада.

То есть пользователь начинает понимать, что фасад состоит из повторяющихся простых элементов.

3. Окно

Теперь можно сделать первое полноценное упражнение на один архитектурный элемент.

Рисунок: классическое прямоугольное окно.

Шаги:

внешний контур;
внутренняя рама;
вертикальное деление;
горизонтальное деление;
подоконник;
простая декоративная рамка;
верхний элемент.

Не нужно делать сложную лепнину.

Финальный рисунок: красивое, но очень простое архитектурное окно.

4. Дверь и дверной портал

Следующее упражнение немного сложнее окна.

Рисунок: входная дверь классического здания.

Элементы:

дверь;
дверная коробка;
простой портал;
горизонтальный карниз сверху;
небольшие боковые элементы;
ступенька.

Здесь пользователь впервые рисует архитектурную композицию вокруг проёма.

5. Колонна

Очень важное упражнение для дальнейшего курса.

Рисунок: простая классическая колонна.

Последовательность:

основание;
вертикальный ствол;
простая капитель;
верхний карниз.

Можно добавить рядом вторую колонну, чтобы показать повторение архитектурного элемента.

Навык: симметрия, повторение и аккуратные вертикальные линии.

6. Небольшой фрагмент фасада

Теперь объединяем предыдущие элементы.

Рисунок: небольшой участок классического фасада.

В нём:

две колонны;
центральная дверь;
два окна;
цоколь;
горизонтальный карниз;
верхняя декоративная линия.

То есть пользователь уже не рисует отдельное окно или колонну — он собирает маленький кусок здания.

7. Простой фасад здания

Следующий уровень — полноценный фасад.

Рисунок: небольшой симметричный фасад.

Например:

прямоугольный основной объём;
центральная дверь;
4–6 окон;
несколько колонн/пилястр;
карниз;
простой треугольный фронтон;
ступени.

Причём строго фронтальный вид.

Это уже должен быть настоящий архитектурный рисунок, но построенный из очень простых элементов.

8. Небольшой дом

Финал раздела.

Рисунок: небольшой классический дом, вид спереди.

Состав:

основной фасад;
крыша;
центральный вход;
несколько окон;
колонны или пилястры;
карниз;
фронтон;
ступени;
небольшие архитектурные детали.

При этом дом должен оставаться достаточно простым, чтобы его можно было последовательно нарисовать примерно за 20–30 осмысленных шагов.
